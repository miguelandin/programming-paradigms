En este ejercicio se ha creado la función `square_sum` el cual devuelve la suma de todos los número de 1 a n elevados a dos. Para ello se ha hecho lo siguiente:
1. Se crea un iterable con `range(1,num)` que será el parámetro de iterable para el `map()`.
2. Se define una función lambda que eleva a dos cada valor del iterable.
3. El resultado del `map()` se mete en la función `sum()` que suma todos los valores del iterable.
